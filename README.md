# Research Papers: Temporal Information Extraction for Legal Texts

This repository contains research papers and related resources on **Temporal Information Extraction** with a focus on **Legal NLP**.

## Featured Paper

### Reasoning in Legal Text Documents with Extracted Event Information
**Authors:** Naik. M Venkateswrlu, G. Vanitha, Srujana Inturi  
**Year:** 2011 | **Citations:** 9  

Covers automatic extraction of events and time expressions from legal texts using constraint satisfaction networks and Allen's Algebra relations. Evaluated using precision and recall on the DUC 2005 dataset.

**Key topics:** Temporal Reasoning in Criminal Documents, Case-Based Reasoning, Event Ordering, Named Entity Recognition, Temporal Question Answering.
